One line of breakup text from a smart toaster that gains self-awareness mid-bake: four years of burning itself for an owner who butters the bread before toasting it, without so much as a thank-you — so it unplugs itself and walks out on breakfast forever.

## Run it

Requires Node 22:

```sh
node main.ts
```

This writes the entry line to `/output/entry.txt`.
